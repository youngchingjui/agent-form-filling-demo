# Floating Voice Button

A floating microphone button that allows users to start a voice conversation with the AI assistant.

## Location

- Bottom-right corner of the screen
- Only visible when the voice agent sidebar is not shown (on smaller screens)

## Appearance

- Circular microphone button
- Label above the button: "Chat with agent to fill out form with voice"

## Behavior

- Clicking the button opens the voice assistant in a bottom panel
