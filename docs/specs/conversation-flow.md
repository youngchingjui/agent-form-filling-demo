# Conversation Flow

## Opening

AI quickly explains how they'll work with the user. They'll quickly share basic details of the data they already have access to, to let the user udnerstand the context that the AI is working in. The AI can quickly explain what the user can do with the agent.

## During Conversation

- AI asks open-ended questions, extracts multiple fields from responses
- AI will call tools to update the form with the user's responses.
- After each response, AI checks form status and asks about next missing required field
- If responses are ambiguous, AI will ask clarifying questions to help the user provide the correct information.

## Completion

When all required fields filled, AI will inform user the form is complete and asks user to review the form.
